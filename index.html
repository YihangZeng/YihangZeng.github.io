🏆 Competitions & Projects

🎾 2024 MCM/ICM - Honorable Mention

🚄 Asia and Pacific Mathematical Contest in Modeling - Second Prize

🧬 Synthetic Biology Competition - Gold Medal

💊 China Collegiate Computing Contest - Third Prize

Developed an adverse drug reaction prediction model using Python and graph neural networks, integrating knowledge graphs, positive-negative sample balancing, and drug representation algorithms to enhance prediction accuracy.

🛠️ Compiler Principles Course Project

Built a SysY language compiler with an RISC-V backend using C++ and LLVM, implementing lexical analysis, syntax analysis, semantic analysis, intermediate code generation, code optimization, and target code generation. Advanced optimizations included mem2reg, aggressive dead code elimination (ADCE), and sparse conditional constant propagation (SCCP), earning extra credit. This project laid a solid foundation for participating in the National Collegiate Computer Systems Capability Competition - Compiler System Implementation Track.
